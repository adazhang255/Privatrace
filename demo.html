Download your data

everything PrivaTrace holds about you, in one file — the same idea as Instagram's export

The export is assembled in your browser and saved straight to your downloads folder — it is never uploaded anywhere. The JSON file is the complete record; the readable report is the same data formatted for a human; the CSV is just the activity log for spreadsheets.

Because PrivaTrace keeps nothing after the tab closes, an export is the only way to make any of this durable — and then it's an ordinary file you own, in your downloads folder, that you can delete like any other. That's the intended asymmetry: persisting your data should take a deliberate action, while forgetting it should be the default.
